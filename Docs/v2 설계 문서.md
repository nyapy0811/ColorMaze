큰 변경점들
1. 색상 연산 시스템 단순화(필드의 합성기를 이용해 오브를 합치는 방식)
2. 플레이어가 색을 보관하는 방식에서 색상 오브를 보관하는 방식
3. 플레이어는 맵에서 빨강, 초록, 파랑 오브 획득(추후에 더 다양한 색상 가능)
4. 획득한 오브는 맵 재시작 전까지는 재획득 불가
5. 목표 색상은 RGB 각 1~5 사이의 정수 (변동 가능)
6. 플레이어의 색을 이용한 시스템 삭제
7. 문 또는 목적지에 지정된 색의 오브를 제출하는 방식
8. 오브는 합성을 통해 색 변경 가능(예시 : 빨강 2 오브 + 파랑 1 오브 = 빨강2 파랑1 오브 )
9. 숨겨진 오브를 찾는 과정이 더욱 미로에 가까워질것이라 예상


사소한 변경점들
1. 오브는 맵상의 여러 오브젝트에서 추출하는 방식
2. 기본 색은 무채색이고, 상호작용 오브젝트는 색을 가짐
3. 레이저 벽 처럼 여러 칸을 사용하는 기물 추가예정
4. 맵 에디터는 메인 시스템 완성후 그 방식에 맞게 업데이트 전까지 비활성화
5. 맵에서 여러 층을 왕복하는 시스템과 벽이 없어서 떨어질수 있던 시스템 제거

희망 사항
1. 맵을 복셀 시스템에서 3d 오브젝트 배치 시스템으로 변경하고 싶음
