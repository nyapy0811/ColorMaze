Q444. [핵심] 난이도 설정의 형태와 난이도별 차이

1단계 2차 대답 Q443에서 제출 실패 때 알려 줄 정보를 "난이도 설정에 따라 다르게" 하기로 했습니다. 지금 설계에는 난이도 설정이 없으므로, 어떤 형태로 둘지와 난이도마다 무엇이 달라지는지 정해 주세요. (1차 Q40의 "난이도는 경로의 복잡도와 문의 개수로 조절"은 맵을 설계할 때의 난이도이고, 이 질문은 플레이어가 받는 도움의 양을 바꾸는 설정입니다.)

  [설정 형태]
    - 플레이어가 옵션 메뉴에서 고르는 게임 전체 설정 (언제든 바꿀 수 있음)
    - 게임(또는 맵)을 시작할 때 고르고 플레이 중에는 고정
    - 맵 제작자가 맵마다 정함 (플레이어는 못 바꿈)
  [난이도 개수]
    - 두 가지 (쉬움 / 어려움)
    - 세 가지 (쉬움 / 보통 / 어려움)
  [난이도별 실패 안내]
    - Q443의 선택지를 난이도에 하나씩: 쉬움 = 필요한 값과 낸 값 모두 표시, 보통 = 어느 채널이 다른지 방향만, 어려움 = 일치/불일치만
    - 직접 기재
  [난이도가 바꾸는 다른 요소]
    - 실패 안내만 바뀜
    - 문/목적지 목표 라벨에 숫자 값을 보일지도 바뀜 (3단계 Q224)
    - 추출한 오브의 값을 숫자로 보일지도 바뀜 (1단계 Q141은 "추출 후 값 확인 가능")
    - 기타 (직접 기재)

이유: 목표 라벨(3단계 Q224)과 소지 오브(1단계 Q141)에서 값이 숫자로 정확히 보이면, 실패 안내가 알려 주는 값은 플레이어가 이미 아는 정보라서 난이도 차이가 거의 생기지 않습니다. 그래서 난이도가 어떤 정보를 가리는지 함께 정해야 합니다. 설정 형태에 따라 옵션 메뉴(6단계 Q434), 설정 저장 방식(6단계 Q316), save.json 구조가 달라집니다.

Q179. [핵심] 체크포인트의 활성화 방식
(통합 질문: Q179 + Q204)

※ 1단계 답변 반영: 정해진 것: '구역' 개념은 쓰지 않기로 했습니다(1단계 2차 대답 Q435). 따라서 첫 번째 선택지의 '구역에 진입'과 네 번째 선택지(구역 경계선 도달)는 해당 없습니다. 남은 것: 체크포인트에 닿으면 자동 / 조준 + 클릭 / 특정 목표 달성 중 어느 방식으로 활성화할지입니다.

체크포인트는 어떻게 활성화되는가?

  - 플레이어가 닿거나 구역에 진입하면 자동 활성화 (트리거 기반)
  - 조준+클릭으로 수동 활성화 (명시적 상호작용)
  - 특정 목표 달성 시 활성화 (예: 오브 제출)
  - 구역 경계선 도달 시 자동 활성화

이유: 체크포인트가 플레이어의 주의를 요구하는 요소인지 배경 시스템인지가 진행감을 결정하고, 의도하지 않은 활성화 방지와 개발 편의성에도 영향을 준다.

답:플레이어가 닿거나 구역에 진입하면 자동 활성화
