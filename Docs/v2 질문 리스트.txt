[작성 방법]

  - 각 질문의 "답:" 뒤에 자유롭게 적어주세요. 선택지가 있는 질문은 번호/기호만 적어도 됩니다.
  - 모르면 미정이라고 적으면 됩니다. 미정인 항목은 나중에 다시 묻거나, 프로토타입으로 정합니다.
  - [핵심] 표시는 다른 질문의 전제가 되는 항목입니다. 이것부터 답하면 나머지 중 상당수가 정리됩니다.
  - 질문 밖의 생각이 있으면 각 절 끝의 메모나 맨 아래 자유 메모에 적어주세요.
  - 용어: "단위"는 오브가 가진 색 수량 1칸(빨강 1단위 = 빨강 오브 1개 분량)을 뜻합니다.

============================================================
 A. 오브의 정체
============================================================

------------------------------------------------------------
Q1. [핵심] 오브 하나는 무엇인가?

  - (a) 빨강 1단위 같은 단일 원색 구슬
  - (b) 맵에 "빨강 3" 같은 수량을 가진 오브도 존재
  - (c) 둘 다

답: 단색 1, 단색 N, 빨강1 파랑2 전부 가능

------------------------------------------------------------
Q2. [핵심] 목표가 RGB 각 1~5이면 합쳐서 최대 15단위가 필요하다. 어떻게 모으는가?

  - 단일 구슬 방식이면 맵에 구슬이 그만큼 흩어져 있어야 하고, 수량형이면 오브 하나가 1~5 값을 가질 수 있다. 어느 쪽인가?

답: 오브 하나가 여러 값을 가진다. 여러 오브를 모아 합성기를 이용해 제출할 하나의 오브 제작

------------------------------------------------------------
Q3. 합성 결과의 각 채널에 상한이 있는가? 5를 넘기면 어떻게 되는가?

  - v1은 0~15 순환이었다. 순환 유지 / 합성 불가로 막음 / 허용(상한 없음) 중 무엇인가?

답: 합성 불가(임시)

------------------------------------------------------------
Q4. 오브의 표현 방식

  - 색을 섞은 "혼합색 구슬"로만 보이는가, R/G/B 숫자가 적혀 있는가?
  - 색만으로는 (3,2,4) 같은 값을 눈으로 구분하기 어렵다. 숫자 라벨도 같이 보여줄 것인가?

답: 개발중 결정 예정

------------------------------------------------------------
Q5. 목표가 "각 1~5"이므로 0은 나오지 않는가?

  - 그렇다면 "빨강만" 같은 단색 목표나 "R,G만" 같은 목표는 없다는 뜻인가?

답: 모든 채널의 범위 0 ~ N

------------------------------------------------------------
Q6. 목표와 정확히 일치해야 하는가, 이상이면 되는가?

  - v1 캔버스는 정확 일치였다.

답: 목표 오브젝트와 제출 오브의 색 완전 일치

------------------------------------------------------------
Q7. "추후 더 다양한 색"은 어떤 방향인가?

  - (a) 노랑/청록 같은 혼합색을 별도 오브로 추가
  - (b) 4번째 원색 채널 추가
  - (c) 아직 모름
  - 참고: 지금 데이터 구조를 "채널 수 가변"으로 만들지, "R/G/B 고정"으로 빠르게 갈지가 여기서 갈린다.

답: 빨강1 파랑2 오브 와 같은 방식

============================================================
 B. 합성기
============================================================

------------------------------------------------------------
Q8. [핵심] 합성기는 맵에 고정된 장치인가?

  - 한 스테이지에 몇 개나 있는가? 위치가 퍼즐의 일부인가?

답: 맵상 핵심 지점에 1개식, 맵에 핵심 지점이 여러개면 여러개 배치 가능

------------------------------------------------------------
Q9. [핵심] 합성기 사용 방식

  - (a) 조준 + 클릭 → 인벤토리의 오브가 자동으로 합쳐짐
  - (b) 합성기 UI를 열어 오브를 골라 넣음
  - (c) 오브를 합성기 위에 놓았다가 결과를 꺼냄
  - (d) 그 외

답: ui 방식

------------------------------------------------------------
Q10. 한 번에 몇 개를 합성하는가?

  - 2개 고정 / 임의 개수

답: 색상 한도를 넘지 않는 범위에서 자율

------------------------------------------------------------
Q11. 합성은 가산(더하기)뿐인가?

  - v1의 감산, 최댓값 보정(ColorChanger), 두 색 교환(StackChanger), 0으로 비우기(Bucket) 같은 연산은 전부 사라지는가?
  - 일부라도 남기고 싶은 연산이 있는가?

답: 감산 방식은 합성용 오브로 -값을 추가할 생각은 있으나, 현재로서는 가산 하나뿐. 가산 감산 이외에는 계획 없음

------------------------------------------------------------
Q12. 합성은 되돌리거나 분해할 수 있는가?

  - 못 되돌린다면 실수로 인한 소프트락(진행 불능)이 생긴다. 그건 "재시작"으로 해결하는 것이 의도인가?

답: 합성 실패시 재시작하는게 의도

------------------------------------------------------------
Q13. 합성에 시간, 연출, 소리가 필요한가?

답: 시간은 필요없고 연출 소리는 필요

------------------------------------------------------------
Q14. 합성기마다 규칙이 다른가?

  - 예: 빨강 전용, 최대 2개까지, 일정 값 이하만 등. 그렇다면 이것이 "기물 종류"를 늘리는 방식인가?

답: 너가 예시를 든 방식은 내가 생각못한 방식, 근데 좋은 방식 같아서 추가 의향은 있음(추후에)

 C. 보관과 획득

Q15. [핵심] 동시에 들고 있을 수 있는 오브 개수에 제한이 있는가?

  - 슬롯 N개 / 무제한
  - 제한이 있으면 퍼즐이 자원관리 쪽으로 간다. 의도한 방향인가?

답: N개. 그래서 합성기와 오브의 위치를 왕복후 제출을 위해 목적지로 이동하는 미로로 설계

Q16. 오브 선택과 사용 UI

  - 핫바 슬롯 / 마우스휠 / 숫자키 / 합성·제출 때만 목록 팝업 / 그 외

답:  합성·제출 때만 목록 팝업

------------------------------------------------------------
Q17. 오브를 땅에 내려놓거나 버릴 수 있는가?

답:  개발중 결정 예정

------------------------------------------------------------
Q18. "추출"은 구체적으로 어떻게 동작하는가?

  - 색이 있는 오브젝트를 조준 + 클릭하면 오브가 인벤토리로 바로 들어오는가?
  - 오브젝트 하나가 오브를 몇 개 주는가?
  - 추출 후 오브젝트는 어떻게 보이는가? (회색으로 변함 / 사라짐 등)
  - 추출에 시간이 걸리는가?

답:  조준 클릭으로 획들, 오브젝트당 1개, 추출후 오브젝트는 무채색으로 전환, 즉시 추출(짧은 추출 효과정도는 가능)

------------------------------------------------------------
Q19. 오브젝트에서 나오는 오브의 값은 고정인가, 랜덤인가?

  - 랜덤이면 재시작마다 값이 달라져 퍼즐이 깨질 수 있어 아마 고정으로 보이지만 확인한다.

답: 고정. 오브젝트의 색과 연동예정

------------------------------------------------------------
Q20. "맵 재시작 전까지 재획득 불가"에서 "재시작"의 정의는?

  - 수동 재시작 / 사망 / 스테이지 재진입 / 체크포인트 중 어디까지 포함되는가?
  - 오브를 문에 제출하거나 합성에 써서 없어졌을 때도 같은 규칙인가?

답: 맵 초기화하는 기능 전부, 맵에 체크포인트가 있다면 구역으로 맵을 구분해서 오브젝트 리셋 구분 (체크포인트 도달 순간으로 맵과 플레이어 복구 하는 방식 예정)

  - 여러 칸을 차지하는 기물로 그 외 후보가 있는가? (이동 발판, 스위치, 텔레포터 등)
  - 이번 v2 범위에는 몇 종까지 포함하는가?

    여러칸 사용하는 다른 기물은 개발하면서 추가 예정 (정해진거 없음)
